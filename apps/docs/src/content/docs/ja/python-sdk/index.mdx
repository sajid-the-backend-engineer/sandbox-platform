Northrays の Python SDK は、Northrays サンドボックスとプログラム的にやり取りするための堅牢なインターフェースを提供します。

## インストール

pip で Northrays の Python SDK をインストールします:

```bash
pip install northrays
```

または poetry を使用します:

```bash
poetry add northrays
```

## はじめに

Northrays の Python SDK を使い始めるためのシンプルな例を示します。

<Tabs syncKey="language">
  <TabItem label="Sync" icon="seti:python">
    ```python
    from northrays import Northrays

    def main():
        # SDK を初期化（既定で環境変数を使用）
        northrays = Northrays()

        # サンドボックスを新規作成
        sandbox = northrays.create()

        # コマンドを実行
        response = sandbox.process.exec("echo 'Hello, World!'")
        print(response.result)

    if __name__ == "__main__":
        main()
    ```
  </TabItem>

  <TabItem label="Async" icon="seti:python">
    ```python
    import asyncio
    from northrays import AsyncNorthrays

    async def main():
        # SDK を初期化（既定で環境変数を使用）
        async with AsyncNorthrays() as northrays:
            # サンドボックスを新規作成
            sandbox = await northrays.create()

            # コマンドを実行
            response = await sandbox.process.exec("echo 'Hello, World!'")
            print(response.result)

    if __name__ == "__main__":
        asyncio.run(main())
    ```
  </TabItem>
</Tabs>

## 構成

SDK は環境変数を使うか、コンストラクタにオプションを渡して設定できます:

<Tabs syncKey="language">
  <TabItem label="Sync" icon="seti:python">
    ```python
    from northrays import Northrays, NorthraysConfig

    # 環境変数を使用 (NORTHRAYS_API_KEY, NORTHRAYS_API_URL, NORTHRAYS_TARGET)
    northrays = Northrays()

    # 明示的な設定を使用
    config = NorthraysConfig(
        api_key="your-api-key",
        api_url="https://app.northrays.com/api",
        target="us"
    )
    northrays = Northrays(config)
    ```
  </TabItem>

  <TabItem label="Async" icon="seti:python">
    ```python
    import asyncio
    from northrays import AsyncNorthrays, NorthraysConfig

    async def main():
        try:
            # 環境変数を使用 (NORTHRAYS_API_KEY, NORTHRAYS_API_URL, NORTHRAYS_TARGET)
            northrays = AsyncNorthrays()
            # 非同期コードをここに記述
            pass
        finally:
            await northrays.close()

        # 明示的な設定を使用
        config = NorthraysConfig(
            api_key="your-api-key",
            api_url="https://app.northrays.com/api",
            target="us"
        )
        async with AsyncNorthrays(config) as northrays:
            # ここにコードを記述
            pass

    if __name__ == "__main__":
        asyncio.run(main())
    ```
  </TabItem>
</Tabs>
