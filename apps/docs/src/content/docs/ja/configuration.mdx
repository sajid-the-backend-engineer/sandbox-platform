## 環境変数を設定する

Northrays で認証するには API キーが必要です。API キーは Northrays プラットフォームから取得できます。

1. [Northrays Dashboard](https://app.northrays.com/dashboard/) にアクセスします。
2. API Keys を開きます。
3. **`Create Key`** ボタンをクリックします。
4. **`.env`** ファイルで **`NORTHRAYS_API_KEY`** 環境変数を設定し、API キーを追加します。
5. **`.env`** ファイルで **`NORTHRAYS_API_URL`** 環境変数を設定し、Northrays の API URL を指定します。

## 構成オプション

Northrays SDK では、Python と TypeScript で `NorthraysConfig` クラスを使用して設定を行えます。`NorthraysConfig` クラスは次のパラメータを受け取ります。

- `api_key`: Northrays の APIキー
- `api_url`: Northrays の API の URL
- `target`: サンドボックスを作成する Northrays のターゲット（リージョン）

<Tabs syncKey="language">
<TabItem label="Python" icon="seti:python">
```python
from northrays import NorthraysConfig

config = NorthraysConfig(
    api_key="your-api-key",
    api_url="your-api-url",
    target="us"
)

```
</TabItem>
<TabItem label="TypeScript" icon="seti:typescript">
```typescript
import { NorthraysConfig } from '@northrays/sdk';

const config: NorthraysConfig = {
    apiKey: "your-api-key",          
    apiUrl: "your-api-url",     
    target: "us"                  
};
```

</TabItem>
</Tabs>

## 環境変数

Northrays SDK は設定に環境変数を利用できます。SDK は次の環境変数を自動的に参照します：

| Variable              | Description                                | Optional |
| --------------------- | ------------------------------------------ | -------- |
| **`NORTHRAYS_API_KEY`** | Northrays の APIキー。                        |          |
| **`NORTHRAYS_API_URL`** | Northrays API の URL。                        | Yes      |
| **`NORTHRAYS_TARGET`**  | サンドボックスを作成する Northrays のターゲット（ターゲット（リージョン））。 | Yes      |

### 環境変数の設定

Northrays SDK は環境変数から設定を読み込みます。以下の方法で設定できます。

- [**`.env`** ファイルを使用](#using-a-env-file)
- [シェル環境を使用](#using-shell-environment)

#### **`.env`** ファイルを使用

プロジェクトのルートディレクトリに `.env` ファイルを作成します：

```bash
NORTHRAYS_API_KEY=your-api-key
NORTHRAYS_API_URL=https://your-api-url
NORTHRAYS_TARGET=us
```

- `NORTHRAYS_API_KEY`: Northrays の APIキー。
- `NORTHRAYS_API_URL`: Northrays API の URL。
- `NORTHRAYS_TARGET`: サンドボックスを作成する Northrays のターゲット（ターゲット（リージョン））。

#### シェル環境を使用

シェルで環境変数を設定します：

<Tabs syncKey="shell">
<TabItem label="Bash/Zsh" icon="seti:shell">
```bash
export NORTHRAYS_API_KEY=your-api-key
export NORTHRAYS_API_URL=https://your-api-url
```
</TabItem>
<TabItem label="Windows PowerShell" icon="seti:powershell">
```bash
$env:NORTHRAYS_API_KEY="your-api-key"
$env:NORTHRAYS_API_URL="https://your-api-url"
```
</TabItem>
</Tabs>

## 設定の優先順位

SDK は設定に対して次の優先順位（高い順）を適用します:

1. コード内で明示的に指定された設定
2. 環境変数
3. 設定ファイル
4. デフォルト値
