---
title: リージョンの選択
---

import { TabItem, Tabs } from '@astrojs/starlight/components'

Northrays は現在、以下のリージョンで利用可能です。

- 米国（US）
- 欧州（EU）

Northrays の[設定](/docs/ja/configuration)手順でリージョンを選択できます。

```python
from northrays import Northrays, NorthraysConfig

config = NorthraysConfig(
    target="us"
)

northrays = Northrays(config)
```

```typescript
import { Northrays } from '@northrays/sdk';

const northrays: Northrays = new Northrays({
    target: "eu"
});
```
