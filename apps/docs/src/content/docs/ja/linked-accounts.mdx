---
title: 連携済みアカウント
---

Northrays は、さまざまなアイデンティティプロバイダーのユーザーアカウント連携をサポートしています。現時点でサポートされているプロバイダーは次のとおりです：

- Google
- GitHub

これにより、Northrays アカウントへのログインに異なるプロバイダーを利用できます。

:::tip

#### より高い使用上限を解放

GitHub アカウントの連携は、Tier 2 へ自動アップグレードされるための要件の一つです。

:::

## アカウントをリンクする方法

アカウントをリンクするには、Northrays ダッシュボードの[Linked Accounts](https://app.northrays.com/dashboard/user/linked-accounts)ページに移動し、リンクしたいアカウントプロバイダーの「Link Account」ボタンをクリックします。

## アカウントの連携解除方法

アカウントの連携を解除するには、Northrays ダッシュボードの [Linked Accounts](https://app.northrays.com/dashboard/user/linked-accounts) ページを開き、連携を解除したいアカウントプロバイダーの「Unlink」ボタンをクリックします。

## さらにサポートが必要ですか？

他のアイデンティティプロバイダーへの対応が必要な場合は、[support@northrays.com](mailto:support@northrays.com) までご連絡ください。
