Northrays の TypeScript SDK は、Northrays のサンドボックスをプログラムから操作するための強力なインターフェースを提供します。

## インストール

npm を使用して Northrays の TypeScript SDK をインストールします：

```bash
npm install @northrays/sdk
```

または yarn を使用します：

```bash
yarn add @northrays/sdk
```

## はじめに

Northrays の TypeScript SDK を使い始めるための簡単な例を紹介します:

```typescript
import { Northrays } from '@northrays/sdk'

async function main() {
  // SDK を初期化（デフォルトで環境変数を使用）
  const northrays = new Northrays()

  // 新しいサンドボックスを作成
  const sandbox = await northrays.create({
    language: 'typescript',
    envVars: { NODE_ENV: 'development' },
  })

  // コマンドを実行
  const response = await sandbox.process.executeCommand('echo "Hello, World!"')
  console.log(response.result)
}

main().catch(console.error)
```

## 設定

SDK は環境変数を使うか、コンストラクターにオプションを渡して設定できます:

```typescript
import { Northrays } from '@northrays/sdk';

// 環境変数を使用 (NORTHRAYS_API_KEY, NORTHRAYS_API_URL, NORTHRAYS_TARGET)
const northrays = new Northrays();

// 明示的な設定を指定
const northrays = new Northrays({
  apiKey: 'your-api-key',
  apiUrl: 'https://app.northrays.com/api',
  target: 'us'
});
```
