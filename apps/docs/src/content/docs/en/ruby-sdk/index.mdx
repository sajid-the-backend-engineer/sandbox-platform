The Northrays Ruby SDK provides a robust interface for programmatically interacting with Northrays Sandboxes.

## Installation

Install the Northrays Ruby SDK using Bundler by adding it to your Gemfile:

```ruby
gem 'northrays'
```

Then run:

```bash
bundle install
```

Or install it directly:

```bash
gem install northrays
```

## Getting Started

Here's a simple example to help you get started with the Northrays Ruby SDK:

```ruby
require 'northrays'

# Initialize the SDK (uses environment variables by default)
northrays = Northrays::Northrays.new

# Create a new sandbox
sandbox = northrays.create

# Execute a command
response = sandbox.process.exec(command: "echo 'Hello, World!'")
puts response.result

# Clean up
northrays.delete(sandbox)
```

## Configuration

The SDK can be configured using environment variables or by passing options to the constructor:

```ruby
require 'northrays'

# Using environment variables (NORTHRAYS_API_KEY, NORTHRAYS_API_URL, NORTHRAYS_TARGET)
northrays = Northrays::Northrays.new

# Using explicit configuration
config = Northrays::Config.new(
  api_key: 'your-api-key',
  api_url: 'https://app.northrays.com/api',
  target: 'us'
)
northrays = Northrays::Northrays.new(config)
```

## Environment Variables

The SDK supports the following environment variables:

| Variable | Description |
|----------|-------------|
| `NORTHRAYS_API_KEY` | API key for authentication |
| `NORTHRAYS_API_URL` | URL of the Northrays API (defaults to `https://app.northrays.com/api`) |
| `NORTHRAYS_TARGET` | Target location for Sandboxes |
| `NORTHRAYS_JWT_TOKEN` | JWT token for authentication (alternative to API key) |
| `NORTHRAYS_ORGANIZATION_ID` | Organization ID (required when using JWT token) |
