## NorthraysAuthenticationError

Error thrown when authentication fails (HTTP 401).

**Properties**:

- `errorCode?` _string_ - Machine-readable error code if available
    - _Inherited from_: `NorthraysError.errorCode`
- `headers?` _AxiosHeaders_ - Response headers if available
    - _Inherited from_: `NorthraysError.headers`
- `statusCode?` _number_ - HTTP status code if available
    
    - _Inherited from_: `NorthraysError.statusCode`




**Example:**

```ts
try {
  for await (const sandbox of northrays.list()) {
    console.log(sandbox.id)
  }
} catch (error) {
  if (error instanceof NorthraysAuthenticationError) {
    console.log(error.statusCode)
  }
}
```

- `NorthraysError`
