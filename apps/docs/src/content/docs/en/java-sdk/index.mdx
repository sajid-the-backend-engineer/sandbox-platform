The Northrays Java SDK provides a robust interface for programmatically interacting with Northrays Sandboxes. It targets Java 11+ and uses OkHttp and Jackson.

## Installation

### Gradle

Add the Northrays SDK dependency to your `build.gradle.kts`:

```kotlin
dependencies {
    implementation("io.northrays:sdk:x.y.z")
}
```

### Maven

Add the Northrays SDK dependency to your `pom.xml`:

```xml
<dependency>
  <groupId>io.northrays</groupId>
  <artifactId>sdk</artifactId>
  <version>x.y.z</version>
</dependency>
```

## Getting Started

### Create a Sandbox

Create a Northrays Sandbox to run your code securely in an isolated environment. The following snippet is an example "Hello World" program that runs securely inside a Northrays Sandbox.

```java
import io.northrays.sdk.Northrays;
import io.northrays.sdk.Sandbox;
import io.northrays.sdk.model.ExecuteResponse;

public class Main {
    public static void main(String[] args) {
        // Initialize the SDK (uses environment variables by default)
        try (Northrays northrays = new Northrays()) {
            // Create a new sandbox
            Sandbox sandbox = northrays.create();

            // Execute a command
            ExecuteResponse response = sandbox.getProcess().executeCommand("echo 'Hello, World!'");
            System.out.println(response.getResult());

            // Clean up
            sandbox.delete();
        }
    }
}
```

## Configuration

The Northrays SDK can be configured using environment variables or by passing a configuration object:

```java
// Using environment variables (NORTHRAYS_API_KEY, NORTHRAYS_API_URL, NORTHRAYS_TARGET)
Northrays northrays = new Northrays();
```

```java
// Using explicit configuration
NorthraysConfig config = new NorthraysConfig.Builder()
    .apiKey("YOUR_API_KEY")
    .apiUrl("YOUR_API_URL")
    .target("us")
    .build();
Northrays northrays = new Northrays(config);
```

For more information on configuring the Northrays SDK, see [configuration](/docs/en/configuration).
