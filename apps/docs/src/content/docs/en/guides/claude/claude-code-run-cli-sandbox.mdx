This guide walks you through running Claude Code inside a Northrays sandbox using the Northrays CLI.

### Prerequisites

- Northrays account and API key (Get it from [Northrays Dashboard](https://app.northrays.com/dashboard/keys))
- Local terminal (macOS, Linux, or Windows)

### Install the Northrays CLI

<Tabs syncKey="os">
  <TabItem label="Mac/Linux">
    ```bash 
    brew install northrays/cli/northrays
    ```
  </TabItem>
  <TabItem label="Windows">
    ```bash
    powershell -Command "irm https://get.northrays.com/windows | iex" 
    ```
  </TabItem>
</Tabs>

:::note
Already have the CLI? Check your version with `northrays --version`. If it's below **0.135.0**, [upgrade to the latest version](https://www.northrays.com/docs/en/getting-started/#cli).
:::

### Authenticate with Northrays

Log in to your Northrays account using your API key:

```bash
northrays login --api-key=YOUR_API_KEY
```

Replace `YOUR_API_KEY` with your actual Northrays API key.

### Create a Sandbox

Create a new sandbox for running Claude Code:

```bash
northrays sandbox create --name claude-sandbox
```

This creates a sandbox named `claude-sandbox`, visible in your [Dashboard](https://app.northrays.com/dashboard/sandboxes). The default Northrays snapshot includes Claude Code, so the command above is all you need.

:::tip
Need more power? Pass `--snapshot northrays-large` or `--snapshot northrays-medium` flag to increase your sandbox resources. See [default snapshots](https://www.northrays.com/docs/en/snapshots/#default-snapshots) for resource details.
:::

### Connect to the Sandbox

SSH into your sandbox:

```bash
northrays ssh claude-sandbox
```

You now have an interactive terminal session inside the sandbox.

### Run Claude Code

Inside the SSH session, start Claude Code:

```bash
claude
```

On first run, Claude Code will prompt you to authenticate:

1. Copy the authentication URL displayed in the terminal
2. Open the URL in your local browser
3. Complete the authentication flow
4. Copy the code provided by the browser
5. Paste the code back into the terminal

Once authenticated, you're all set. Claude Code runs inside the sandbox while you control it from your terminal.
