The Northrays Go SDK provides a powerful interface for programmatically interacting with Northrays Sandboxes. It requires Go 1.25 or later.

## Installation

Install the Northrays Go SDK using go get:

```bash
go get github.com/northrays/sandbox-platform/libs/sdk-go
```

## Getting Started

### Create a Sandbox

Create a Northrays Sandbox to run your code securely in an isolated environment. The following snippet is an example "Hello World" program that runs securely inside a Northrays Sandbox.

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/northrays/sandbox-platform/libs/sdk-go/pkg/northrays"
)

func main() {
	// Initialize the SDK (uses environment variables by default)
	client, err := northrays.NewClient()
	if err != nil {
		log.Fatal(err)
	}

	// Create a new sandbox
	sandbox, err := client.Create(context.Background(), nil)
	if err != nil {
		log.Fatal(err)
	}

	// Execute a command
	response, err := sandbox.Process.ExecuteCommand(context.Background(), "echo 'Hello, World!'")
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(response.Result)
}
```

## Configuration

The Northrays SDK can be configured using environment variables or by passing options to the constructor:

```go
package main

import (
	"github.com/northrays/sandbox-platform/libs/sdk-go/pkg/northrays"
	"github.com/northrays/sandbox-platform/libs/sdk-go/pkg/types"
)

func main() {
	// Using environment variables (NORTHRAYS_API_KEY, NORTHRAYS_API_URL, NORTHRAYS_TARGET)
	client, _ := northrays.NewClient()

	// Using explicit configuration
	config := &types.NorthraysConfig{
		APIKey: "YOUR_API_KEY",
		APIUrl: "https://app.northrays.com/api",
		Target: "us",
	}
	client, _ = northrays.NewClientWithConfig(config)
}
```

For more information on configuring the Northrays SDK, see [configuration](/docs/en/configuration).
