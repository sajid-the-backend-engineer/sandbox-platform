Northrays Model Context Protocol (MCP) server enables AI agents to interact with [Northrays Sandboxes](/docs/en/sandboxes) programmatically. This guide covers how to set up and use the MCP server with various AI agents.

## Install Northrays CLI

Install the Northrays CLI to manage the MCP server.

<Tabs syncKey="os">
<TabItem label="Mac/Linux">

```bash
brew install northrays/cli/northrays
```

</TabItem>
<TabItem label="Windows">

```bash
powershell -Command "irm https://get.northrays.com/windows | iex"
```

</TabItem>
</Tabs>

## Authenticate with Northrays

Authenticate with Northrays to enable MCP server access.

<Tabs>
<TabItem label="CLI" icon="seti:shell">

```bash
northrays login
```

</TabItem>
</Tabs>

## Initialize MCP server

Northrays provides methods to initialize the MCP server with your preferred AI agent. Supported agents include Claude, Cursor, and Windsurf.

<Tabs>
<TabItem label="CLI" icon="seti:shell">

```bash
# Initialize with Claude
northrays mcp init claude

# Initialize with Cursor
northrays mcp init cursor

# Initialize with Windsurf
northrays mcp init windsurf
```

</TabItem>
</Tabs>

After initialization, open your AI agent application to begin using Northrays features.

## Configure MCP server

Northrays provides methods to generate MCP configuration for integration with other AI agents.

<Tabs>
<TabItem label="CLI" icon="seti:shell">

```bash
northrays mcp config
```

</TabItem>
</Tabs>

This command outputs a JSON configuration that you can copy into your agent's settings:

```json
{
  "mcpServers": {
    "northrays-mcp": {
      "command": "northrays",
      "args": ["mcp", "start"],
      "env": {
        "HOME": "${HOME}",
        "PATH": "${HOME}:/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin:/opt/homebrew/bin"
      },
      "logFile": "${HOME}/Library/Logs/northrays/northrays-mcp-server.log"
    }
  }
}
```

:::note
For Windows users, add the following to the `env` field:
<br />
```json
"APPDATA": "${APPDATA}"
```
:::

## Start MCP server

Northrays provides methods to manually start the MCP server.

<Tabs>
<TabItem label="CLI" icon="seti:shell">

```bash
northrays mcp start
```

</TabItem>
</Tabs>

## Available tools

Northrays MCP server provides the following tools for interacting with Northrays Sandboxes:

- [Sandbox management](/docs/en/sandboxes)
- [File system operations](/docs/en/file-system-operations)
- [Git operations](/docs/en/git-operations)
- [Process and code execution](/docs/en/process-code-execution)
- [Computer use](/docs/en/computer-use)
- [Preview](/docs/en/preview)

## Troubleshooting

To troubleshoot issues with the Northrays MCP server, try the following:

- **Authentication issues**: run `northrays login` to refresh credentials
- **Connection errors**: verify MCP server configuration, check server status
- **Sandbox errors**: use `northrays list` to check sandbox status

If the issue persists, contact [support@northrays.com](mailto:support@northrays.com).
